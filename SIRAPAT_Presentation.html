Tantangan Tata Kelola Ruang Rapat Sebelumnya

Sebelum hadirnya ROOMBOOK, koordinasi peminjaman ruang rapat menghadapi kendala administratif dan operasional harian.

Bentrok Jadwal (Double Booking)

Pencatatan manual via WhatsApp dan buku kertas memicu tabrakan jadwal antar unit kerja pada jam yang sama.

Status Ruangan Buta (No Real-Time)

Pegawai harus mendatangi pintu fisik ruangan hanya untuk mengecek apakah ruangan kosong atau sedang digunakan.

Verifikasi Persetujuan Lambat

Ruang strategis (Ruang Sekjen & VIP) membutuhkan kepastian approval pimpinan yang sering tertunda.

Ketiadaan Jejak Audit

Sulit merekapitulasi utilisasi fasilitas, riwayat pemohon, dan laporan pertanggungjawaban operasional.

Transformasi Digital

Solusi Terpadu: ROOMBOOK (SIRAPAT)

Satu ekosistem berbasis web terintegrasi yang menjawab seluruh kebutuhan pemohon, pengelola, dan pimpinan.

Arsitektur & Keamanan

Arsitektur Sistem & Integrasi Google Service Account

Dibangun dengan standar performa tinggi, ketahanan data relasional, dan protokol keamanan data terenkripsi.

Teknologi Modern (Tech Stack)

Frontend: React 18, TypeScript, Tailwind CSS, Vite, Lucide Icons, Canvas Confetti.
Backend REST API: Node.js, Express, Helmet, CORS, Rate Limiting (100 req/min).
Database: PostgreSQL ACID-Compliant dengan Foreign Keys, ENUM status, & Indexing.
Integrasi Eksternal: Google Calendar API v3 via Service Account OAuth 2.0.

Protokol Keamanan & Sinkronisasi

Bcrypt Hashing & Validasi Password Ketat

Kombinasi huruf besar, kecil, angka, simbol, serta proteksi Anti-Bruteforce.

Parameterized SQL Queries

Proteksi 100% dari celah keamanan SQL Injection pada seluruh endpoint API.

Dual-Direction Calendar Sync

Penghapusan event di DB lokal otomatis menghapus slot di Google Calendar secara real-time.
